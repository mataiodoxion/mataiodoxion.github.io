Q7 Print Hide using substrings - write code#

Consider the following code segment.

String original = "DEFGHI";
String result = /* missing code */;
System.out.println(result);

Which of the following can be used to replace /* missing code */ so that this code segment prints the string "HIDE"?

I chose (A) original.substring(4) + original.substring(0, 1), which was wrong, because substring(a, b) extracts substrings from index a to b-1. The correct answer would be (B) original.substring(4) + original.substring(0, 2) to account for that indexing error.

Q19 Statement using random numbers - describes behavior#

Consider the following statement.

int r = (int) (Math.random() * 6) + 10;

Which of the following best describes the behavior of the statement?

I wrongly chose (D) It generates a random integer between 10 and 16, inclusive, and assigns it to r. Collegeboard's Math.random() generates a random float between 0 (inclusive) and 1 (exclusive), which means that it would be impossible for Math.random() * 6 to ever produce the integer 6. The correct range would be from 0+10=10 to 5+10=15, so (C) It generates a random integer between 10 and 15, inclusive, and assigns it to r.

Q35 Method that traverses numbers - describe behavior#

Consider the following method.

public static boolean mystery(ArrayList<Integer> numbers)
{
  int prev = Integer.MAX_VALUE;
  for (int num : numbers)
  {
      if (num > prev)
      {
          return false; 
      }
      prev = num;
  }
  return true;
}

Which of the following best describes the behavior of the method?

I incorrectly selected (C) It returns true if numbers is sorted from least to greatest and returns false otherwise.. This is likely due to misreading the comparison num > prev, which would be checking if the next number of greater than the last (checking least to greatest), and returns false if that is the case. The correct answer is (D) It returns true if numbers is sorted from greatest to least and returns false otherwise.

Q41 Traverse colors array - determine result#

Consider the following code segment.

String[] colors = {"red", "green", "orange", "black", "yellow", "brown"};
int result = -1;
for (int j = 0; j < colors.length; j++)
{
    for (int k = j + 1; k < colors.length; k++)
    {
       if (colors[j].length() == colors[k].length())
        {
            result = k;
        }
    }
}

What is the value of result after executing this code segment?

The code segment returns the segment of the second index of the last match of subsequent strings in an array of strings. I selected (C) 4, but it would take the index of the match after. So, for "black" and "brown" (the last match), the program would return the index of "brown", which is (D) 5.
